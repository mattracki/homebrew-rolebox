# Homebrew tap for Rolebox

This is the official Homebrew tap for
[Rolebox](https://github.com/mattracki/rolebox).

Once the first release is published, install the CLI with:

```sh
brew install mattracki/rolebox/rolebox
```

Install the optional desktop application with:

```sh
brew install --cask mattracki/rolebox/rolebox-app
```

The installable formula and cask are generated from the templates in this
repository when a Rolebox release is published.
